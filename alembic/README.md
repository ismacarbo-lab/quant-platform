Alembic is configured against PostgreSQL via `Settings.database_url`.

Phase 1.0 revision `0001_ingestion` creates research ingestion tables only
(`data_sources`, `instruments`, `ingestion_runs`, `daily_bars`). It does not
create orders, trades, or broker tables.

```bash
docker compose up -d postgres
uv run alembic upgrade head
uv run alembic current
uv run python scripts/check-db.py
```

Downgrade (destroys ingestion tables):

```bash
uv run alembic downgrade -1
```

Always review autogenerated revisions before applying them.

Do not point Alembic at SQLite. `Settings` rejects non-PostgreSQL URLs.

Stop the database with `docker compose down`.
